# 🌿 AirLog Buddy Pro

**AirLog Buddy Pro** is a beginner-friendly tool for tracking and visualizing air pollution data — developed using **Python** and **Streamlit**, with care by the 18-TGL Team 💚

---

## 🚀 Features

- 📅 **Log daily air quality** for PM10, PM2.5, SO₂, NOₓ, and O₃  
- 📊 **Visualize pollutant trends** via interactive charts  
- 📌 **Compare multiple pollutants** side-by-side  
- 📤 **Export filtered entries to CSV** for further analysis  
- 📱 **Mobile-friendly** and easy to use — no login or installation required  

### 📣 Upcoming (Paid) Features
- PDF export

- Stack Monitoring Visualizations

---

### 📥 How to Use
1. Click the app link.
2. Enter air quality readings and your location.
3. View charts instantly.
4. Download data.(CSV Excel)

---

## ⚠️ Known Notes (Transparency is key!)

- **PM2.5 chart** might not show results immediately after new entries. We’re improving this!
- For best results, **filter by the same location name** you entered earlier.
- **Date format** may vary depending on device/browser. Stick to the calendar picker if possible.
