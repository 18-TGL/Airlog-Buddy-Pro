# 🌿 Airlog Buddy Pro

**Airlog Buddy Pro** is a beginner-friendly air quality logging and visualization tool built using Python and Streamlit.

🚀 Features:
- Track daily air pollution for PM10, PM2.5, SO₂, NOx, and O₃.
- Visualize trends using interactive bar charts.
- Multi-pollutant comparison (side-by-side).
- Export filtered data to CSV.
- Mobile-friendly & easy to use.

📦 Tech Stack:
- Python
- Streamlit
- Altair
- Pandas

🧪 Perfect for:
- Environmental scientists
- Students and teachers
- Urban air quality monitoring
- Grassroots organizations
